# Smart University Lost & Found 🎓

A web-based platform designed to provide a centralized solution for reporting, searching, and recovering lost and found items within a university campus.

## 📌 Project Overview

**Smart University Lost & Found** aims to make it easier for students, faculty members, and university staff to report lost or found belongings.

Currently, lost and found information is often shared through class groups, emails, word of mouth, and notice boards. This project aims to bring all these activities into one centralized and user-friendly web platform.

The system will allow users to report lost items, report found items, search existing reports, view item details, and track recovery status.

## 🎯 Project Objectives

- Centralize university lost and found information.
- Make reporting and searching easier.
- Reduce dependency on scattered communication channels.
- Help users identify potentially matching lost and found items.
- Improve the overall item recovery process.

## ✨ Planned Features

### 1. User Module
- User registration and login interface.
- User profile.
- Report management.

### 2. Lost & Found Module
- Report lost items.
- Report found items.
- View lost and found listings.
- View individual item details.

### 3. Search & Filter Module
- Search for lost and found items.
- Filter by category.
- Filter by location.
- Filter by date, color, and status.

### 4. Smart Matching Module (Optional)
- Identify potentially related lost and found reports.
- AI-assisted description similarity.
- Display possible matches.

### 5. Recovery Module
- Track item recovery status.
- Mark items as recovered or returned.

### 6. Admin Module
- Manage reports and categories.
- Moderate inappropriate content.
- Review suspicious reports.

## 🚀 Getting Started

Follow these steps to run the frontend locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Alternatively, use the VS Code Live Server extension to run the website.
